# 打工人记账器 v1.2.2

## 修复：切换计时方式后「钱又冒出来」

上一版切模式时旧钱确实作废了，但切到全自动/定点打卡后，程序立刻按班次从早上 8:00
把今天整天补算了一遍 —— 弹窗写着「从 0 重新开始」，屏幕上却是 ¥190 / ¥333 / ¥380。

现在切换会记下**切换那一刻**，本班从那时起算：

| 场景 | 以前 | 现在 |
|---|---|---|
| 18:50 切到全自动（已过下班点） | ¥380.95 | **¥0.00**，状态「今天过点了」 |
| 12:00 切到全自动 | ¥190.48（补算 4 小时） | **¥0.00**，之后从 12:00 起算 |
| 16:00 切到全自动 | ¥333.38（补算 7 小时） | **¥0.00**，之后从 16:00 起算 |

- 起算点只对**当天这一班**有效，次日/下一班自动失效
- **定点打卡**不受影响：它仍是「按设定班次全天计薪」，早退也拿全天
- 切换时已过下班点 → 不再补算，也不再往明细里写一条 ¥0.00

## 修复：「已工作」和金额对不上

全自动已收工后把上班时间 08:00 改成 09:00，金额还是 8 小时的 ¥380.95，
但「已工作」变成 07:00:00 —— 再结算一次甚至变成 15:00:00（重复累加）。

现在工时用「真正结算的秒数」显示，改班次时收工标记跟着挪到新班次上。
