# 打工人记账器 v1.2.4

## 修复：默认值提示「说让你点黄条，但黄条不见了」

用默认工资时，首页那条黄色提醒会在版面收紧（`body.tight2`）时被 `display:none` 藏掉，
而顶部飘的提示还在说「随时点顶部黄条改」—— 用户按提示去找，找不到。

- 黄条改成分级收纳：正常完整显示 → 版面紧时**压成一行小字但仍在** → 实在放不下（新增三级）才隐藏
- 提示文案改成指向「改一下」（那个按钮始终可见）
- 点「改一下」时如果还没确认真实工资，**光标直接落在「月到手」输入框并全选**

## 提示气泡重做

| | 以前 | 现在 |
|---|---|---|
| 底色 | 深棕紫块 | 暖白 + 粉色描边 |
| 文字 | 纯白 700 | 深粉灰 600，行高 1.5 |
| 圆角 | 12px | 14px |
| 阴影 | 深色硬阴影 | 柔和粉色投影 |
| 停留 | 1.5 秒 | **2.8 秒** |
| 位置 | 压在黄条上 | 自动让到黄条下方 |
