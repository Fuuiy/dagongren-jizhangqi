【第一次打开是什么样】
  · 第一次打开会自动弹出参数面板，默认是「早八晚五」：08:00 上班、17:00 下班、午休 12:00–13:00
  · 主界面是空的：今日已赚 ¥0.000、已工作 00:00:00、目标 0.0%
  · 月薪默认填了 8000、目标默认「买台新手机 ¥5,999」，都可以直接改
  · 填好点「存好啦」，之后每次打开都会记住


【怎么打开】
  双击本文件夹里的「打工人记账器.exe」就行。
  想放到桌面：右键这个 exe → 发送到 → 桌面快捷方式。
  也可以右键 → 固定到任务栏，之后点一下就能开。


【安装版（推荐发给朋友的方式）】
  · 项目里的 release 文件夹有个「打工人记账器-1.0.0-安装包.exe」（约 88 MB），
    把这一个文件发给对方，双击 → 下一步 → 装完自动有桌面图标和开始菜单图标
  · 不需要管理员权限；卸载在 Windows「设置 → 应用」里，卸载不会删记账数据
  · 第一次运行如果 Windows 弹蓝色的「未知发布者」提示，
    点「更多信息 → 仍要运行」即可（个人软件没有买签名证书的正常现象）
  · 首次若弹防火墙提示：允许或拒绝都行，拒绝只是不联网拉节假日安排


【第一次打开要填什么】
    · 月到手（税后）—— 填实际到卡里的那个数（不含年终奖）
                     右边会立刻显示「日薪 ¥X · 时薪 ¥Y」，当场核对
    · 每月工作天数 —— 点一下就选好：双休 / 大小周 / 单休，
                     天数按当月实际工作日自动算（已扣法定节假日）
                     想填别的（比如只上 20 天）直接改右边数字
    · 上班 / 下班时间 —— 两种填法，随便挑：
                     ① 直接打字：点一下整段时间会被选中，直接打 1500 就是 15:00；
                        想改某一位就再点一下定位光标，改哪一位就只改那一位，
                        不会再把你打的时间打乱重排
                     ② 点右边的小时钟：弹出滑块，拖「时」「分」两条滑杆，
                        或者点「现在 / 09:00 / 12:00 / 13:00 / 18:00」一键到位
                     打 9     → 09:00
                     打 1532  → 15:32
                     打 2359  → 23:59
    · 每日有效工时（小时）—— 这个数字决定你每小时值多少钱。
                     填 7 就是你干满 7 小时拿满日薪，第 8 小时起算加班。
                     不填就按「下班 − 上班 − 午休」自动算。
                     只在「打卡那一刻」模式下出现。
    · 午休时段    —— 填你自己的那一段，比如 12:00 – 13:30。
                     只有落在上班时段里的午休才会被扣掉；
                     如果你的班是 00:00–08:00，那 12:00 的午休
                     本来就不在班上，界面会提示「不会被扣除」。

  跨夜班也能用：上班 22:00、下班 06:00，程序会认成「昨晚到今早」这一班。


【三种模式，先选对再用】
  设置里「计时方式」是三张卡片，点一下选中，下面会写清当前规则。

  ┌─ ① 打卡那一刻 ───────────────────────────┐
  │ 完全按你自己的打卡走，上下班时间管不着你。  │
  │                                          │
  │ · 凌晨、周末、半夜，什么时候都能打卡        │
  │ · 只记「上班打卡」到「下班打卡」这段真时间  │
  │ · 加班到几点就记到几点                      │
  │ · 加班不算「超出班次」，照样计钱            │
  │                                          │
  │ 按钮：上班打卡 → [⏸ 午休一下] [🏃 下班啦]  │
  │       点午休即暂停，点继续接着算            │
  └──────────────────────────────────────────┘

  ┌─ ② 按上班时间 · 要打卡（自动开关关掉）────┐
  │ 打卡时间放宽，但钱只按你填的时间算。        │
  │                                          │
  │ · 上班前 30 分钟就能打卡（不用掐点）        │
  │ · 打完卡，计薪仍从你填的上班时间开始        │
  │   例：填 09:00，08:35 打卡，9 点开始算钱   │
  │ · 下班后 30 分钟内还能打卡，               │
  │   但金额到下班时间点就停住，不再变化        │
  └──────────────────────────────────────────┘

  ┌─ ③ 按上班时间 · 自动计时（开关打开）──────┐
  │ 什么都不用点，全交给系统时间。              │
  │                                          │
  │ · 到点自动开始 / 午休自动暂停 / 自动继续    │
  │ · 到下班的点自动结算                        │
  │ · 界面上所有按钮都是灰的，点不动            │
  └──────────────────────────────────────────┘


【按钮几种状态（手动模式）】
  · 还没到上班点（灰）—— 没到打卡窗口，点不动
  · 上班打卡（粉）    —— 可以开始计时
  · 午休一下（黄）    —— 暂停计时
  · 继续计时（青）    —— 从这一刻接着算
  · 下班啦（绿）      —— 结算这一班
  · 今日已收工（紫）  —— 这一班结束了
                        点错了？下面有「↩ 撤销下班」可以撤销
  · 今天已过点（灰）  —— 过了下班 +30 分钟，今天不补了


【几个数字分别是什么意思】
  · 大字「今天已经赚了」—— 到今天此刻的累计，会实时往上滚；
                            **封顶一个日薪**，超出部分不再加钱；
                            收工后停在「本班一共赚了多少」
  · 紫色「加班 x:xx」  —— 干满应出勤时长后才出现，只记时长不折钱
  · 「每秒 +x」        —— 每秒钟的进账速度，是个固定值
                          （月薪 ÷ 天数 ÷ 每日有效工时 ÷ 3600）
                          它不会变，变的是上面那个累计
  · 浮起来的 +¥x.xxxx  —— 每秒真的到账多少，钱少时显示到小数点后四位
  · 时薪 / 日薪 / 分薪 / 秒薪 —— 四档换算
  · 目标进度条         —— 攒到目标还差多少、还要上多久班
  · 今天的时间轴       —— 上班、午休、下班，以及你走到哪了
                          「打卡那一刻」模式下，起点是你真实的打卡时刻
  · 今天赚的钱 ≈       —— 换算成奶茶、午饭、电影票


【“今日已收工”到底什么时候出现】
  · 全自动：只看时间。到了下班点才显示已收工，到点金额立刻停住（等于日薪）
  · 定点打卡：你自己点「下班啦」才算收工；下班 30 分钟内还能补点，金额按设定班次算
  · 打卡那一刻：点「下班啦」才算收工
  三种模式各自独立，切换模式时会清掉上一套规则留下的状态，
  不会出现「已经显示收工、金额却还在涨」这种打架的情况。


【跨夜班怎么填】
  · 上班 22:00、下班 06:00 —— 下班时间只要早于上班时间，程序就当作跨夜班
  · **只要跨过 24 点就会提示**，不用等错误发生：
      面板里：跨夜班：22:00 → 次日 06:00，共 8 小时（浅紫）
      主界面时间轴里同样有一行
  · 跨夜超过 12 小时会升级成橙色警告，并提示你可能想填的时间
      （比如 08:00 填成 05:30，会问「是不是想填 17:30？」）
  · 时间轴右下角标「次日」两个字，一眼看出下班不是今天
  · 注意：跨夜班在凌晨时，算的是「昨天那班」，所以「已工作」看起来会比较长，这是对的
  · 在 22:00–06:00 这种夜班里，钱不会被午夜 0 点切断：
    打卡那一刻模式会一路算到你按「下班啦」（或第二天 06:00 之后自动收口）；
    全自动模式会在 06:00 一过就把整班结算掉，记到「上班那一天」的明细里；
    凌晨补录、改薪固化的钱也记在「上班那一天」，不会跑到第二天

【改班会重新算今天】
  · 改上班 / 下班 / 午休时间 = 换了整天的时间口径，今天的数字会按新班次从 0 重算
  · 已经进过历史累计的钱不会丢，也不会被重算
  · 改月薪、改工作天数不会重算今天（只影响从此刻起的单价）


【补录还能看到补了啥】
  补录弹层下半部分会列出「今天已补 N 段 · 共 ¥X」，
  每段显示 时间段 · 时长 · 补了多少钱，不用凭记忆。
  再次打开补录时，默认时间会自动避开已经补过的段，不会一打开就撞车。

【每日明细】
  目标卡右下角「明细」：按月份分组列出每一天赚了多少，
  今天那行标「进行中」（金额实时涨），请过假的那天标「请假」。
  最多显示最近 62 天，按月汇总「共 ¥X · N 天」。
  天数只数「真赚到钱」的天，和主界面「本月已赚 · N 天」同一个口径；
  请假日单独写成「· 请假 N 天」，不混进合计里。

【万一没存进去，会告诉你】
  极少数情况（磁盘写满、文件被占用、系统权限异常）存档会写不进磁盘。
  这时顶部会出现一条橙色提示「刚才没存进磁盘」，点「重试保存」即可；
  程序也会每 5 秒自动重试一次，关闭窗口前还会再抢救一次。
  没有再出现这条提示，就说明已经存好了。

【数据备份（换电脑 / 防丢）】
  设置面板最下面：
    · 导出数据 → 选个位置存成 .json，文件名带日期
    · 导入数据 → 选备份文件，会先显示里面有什么（月薪、累计），
      按钮变成「确认导入？」再点一次才真的覆盖，8 秒不点自动取消
    · 导入前会自动把当前数据留一份在本地（dgjz.worker.v1.bak），
      万一导错了还有得救
    · 不是本应用的 json 会被拒绝，不会把别的文件灌进来

【小窗模式（只留“今天已经赚了”）】
  窗口底部有一条横杠，正常和迷你两种状态都能点：
    · 正常状态：底部一条**较短**的灰杠（鼠标移上去变长变粉）→ 点它缩成小窗
    · 迷你状态：同一条横杠变成**更长**的粉色杠 → 点它展开回完整面板
    · 标题栏左边那个箭头按钮也一样：完整时箭头朝上（收起），迷你时朝下（展开）
    · 迷你窗口只收上面那段：只留标题栏 + 今日已赚那张卡，
      卡片的宽度、字号一个像素都不变（不是把整张卡缩小），像贴在屏幕角上的便签
    · 展开时宽度、高度都回到**缩小前那一份**：不会再出现“迷你时被拉宽了，
      展开后一直占满整个屏幕”的情况
    · 展开回到原位：左下角留在原地，只在贴边时往回收一点，不会跑到屏幕外面
    · 小窗里点齿轮 ⚙ = 先自动复原成完整窗口，再把设置面板打开
    · 关掉程序再打开，会以完整面板启动（小窗状态不记忆）

【窗口大小 / 能不能拉动】
  · 这是桌面小工具，主界面**不能上下拉动**（没有滚动条）：所有卡片一屏排好
  · 窗口大小也只有两种形态，由底部横杠切换：宽度始终不变，只收放下半部分，
    **拖窗口边缘不会改变大小**（避免拖小之后卡片被裁掉、或者拖出一片空白）
  · 想挪位置：拖标题栏（有猪头那一行）即可，位置随你，大小不变


【点 × 不等于退出（收进右下角托盘）】
  · 点窗口右上角的 ×：窗口收起，跑到任务栏右下角通知区（可能要点小箭头「^」才看得到）
    —— 程序还在跑，计时一秒都没停，攒的钱照样在涨
  · 第一次收起会冒一个小气泡提示「还在后台计时」
  · 想叫回来：点一下右下角那个小图标（单击是开关：显示/隐藏）
  · 右键那个小图标有菜单：
        显示主界面 / 隐藏到托盘
        缩成小窗 / 展开完整面板
        退出打工人记账器   ← 只有这里点才是真退出
  · 任务栏图标没了是正常的（收进托盘了）；再双击桌面图标也能叫出来，不会开第二个
  · 注意：Windows 的「通知区」默认会把新图标折叠进「^」，找不到就点一下 ^


【切换计时方式，今天的钱会重新算（重要）】
  · 三种计时方式（打卡那一刻 / 定点打卡 / 全自动）算钱口径完全不同，
    所以**一旦切换并保存**，今天已经按旧方式算出来的金额会清零，从 0 重新开始
  · 切完不会自动帮你打卡：状态回到「还没打卡」，要你自己点一下打卡按钮
  · 手动「补录」的那几段钱**不会被清掉**（那是你自己加的），切完还在
  · 只改月薪、上班时间、目标这些，不换计时方式，则**不会**清零
  · 已经收工的当天切换，也会按新方式重算一次（历史里别的日期一律不动）
  · 想保留今天的旧数字就别切；确实切了，就当今天重新开始


【齿轮】
  右上角 ⚙ 点一下张开设置，再点一下收起（张开时齿轮会转一下）。


【工作天数怎么算的】
  不再是固定的 21.75 / 22 / 26，而是**按当月实际**：
    · 双休 = 当月的周一~周五
    · 单休 = 只休周日
    · 大小周 = 双休 + 隔周周六
  并且**自动扣掉法定节假日、加上调休上班日**（内置 2025/2026 真实数据，
  有网时自动更新；每年 12 月中下旬会提前拿下一年的）。
  例：2026 年 10 月双休 = 18 天（国庆放 5 个工作日、10-10 调休上班）
      2026 年 2 月双休 = 16 天（春节）
  切换模式或跨月时自动重算，日薪时薪立刻跟着变。
  手动改天数 = 自定义，不再自动跟随月份变化。

【补录 = 加班，三种模式都能补】
  时间轴上都有「补录」。**补进去的时间就是加班，全额算钱，不封顶**：
    08:00–17:00 的班，补 06:00–08:00 → 提示「2 小时 · 班外加班，可补 ¥95.24」
    到手的钱会超过日薪，因为那是加班挣的，不是把日薪重复领一遍。
    · 打卡模式：班内、班外都能补；班外那段单独记成「加班」，
      主界面会出现「加班 2:00」小药丸，「已工作」也把这段算进去
    · 全自动 / 定点打卡：班次内已经整段算过钱了，所以只补**班外**那段；
      填到班内会直接说明「班次内不用补，要补加班就填 18:00 之后」
    · 补的时段跨了班次边界也没关系，会自己拆成「班内 + 班外加班」分别算
    · 每一种填不成都会直接说明理由（不再默默截断、不再沉默）：
        空着 / 乱码 →「先填上」「看不懂，像 09:00 这样填（最大 23:59）」
        开始=结束   →「同一时刻，至少补 1 分钟」
        填反了      →「结束时间早于开始时间，是不是填反了？」
        未来时间    →「还没到（现在 xx:xx），只能补已经过去的」
        整段是午休  →「午休本来就不算钱」
        太早了      →「只能补这一班前后一段时间（最早 05:00）」
        撞车        →「和已补过的 xx:xx–xx:xx 重叠了，换一段」
        正在计时    →「你正在计时，补进去会重复算钱」
        请过假      →「请假不计薪，补进去也不会加钱」
        已收工      →「这段已经在 09:00–15:00 那次下班结算里算过了」
    · 夜班跨零点也能补：凌晨 01:30 补「23:00 – 01:00」会被正确算成昨晚到今天，
      提示里会标明「昨天 23:00 – 今天 01:00」
    · 跨过午休会自动扣掉午休；提示里写的是扣完后的真实时长和可补的钱
    · 补错的可以删：弹层里每段右边有「删除」，点一下变「确认?」，
      再点一下才真删；删掉的钱、时长、加班时长会一起退回去
      （3 秒内不点第二下，自动变回「删除」，不会误删）

【时间轴按什么画】
  · 打卡那一刻：**完全按你真实打卡**——
      计时中：左端「10:00 打卡」，右端「预计 19:00」（干满一班的预计时间）
      收工后：左端「10:00 打卡」，右端「15:00 收工」，进度条满格
      不再是设置里填的 08:00–17:00。想改按班次算，就改设置里的班次。
  · 全自动 / 定点打卡：这两类就是按班次算钱的，时间轴画的是班次时间。
  · 忘了点「下班啦」：超过班次时长 4 小时还在跑，时间轴下面会提醒
    「这班已经打了 14:00，是不是忘了点下班？钱到 18:00 就不涨了」。

【本月赚了多少】
  目标卡第二行：「本月已赚 ¥X · N 天」，跨月自动归零重新统计。
  昨天忘下班、今天才结算的钱，会记在昨天，不会算进今天。

【设置入口】
  标题栏右上角的 ⚙ 齿轮 = 设置面板，不用再去目标卡里找「改一下」。


【存之前会拦一下】
  如果你把班次填成明显不合理的值（比如 23 小时、或者午休完全不在上班时间里），
  点「存好啦」不会直接存，而是变成橙色的「确认保存？」，并说明哪里不对。
  再点一次才真正保存；5 秒不点会自动取消，改成正常值再存就行。

【填错数字会怎么样：0 / 负数 / 字母都会被拦】
  设置面板里所有能填数字的地方都有校验，填错了**存不进去**：
    · 月到手填 0 或负数 → 拦住并提示「要大于 0，填 0 或负数算出来时薪就是 0」
    · 月到手小于 100 → 提示「至少 100 元，看看是不是少打了几个 0」
    · 每月工作天数 0 / 负数 / 超过 31 → 拦住
    · 目标金额 0 / 负数 → 拦住（不然进度条直接满格）
    · 已有存款负数 → 拦住；存款留空 = 0，不用逼着填
    · 每日有效工时 0 / 负数 / 超过 24 → 拦住；留空 = 按班次自动算
    · 时间填成 99:99 或空着 → 拦住，并提示「像 09:00 这样填（最大 23:59）」
  出错时：底部会出现一条粉色提示写明是哪个字段、为什么不行，
  那个输入框同时变红；**不用点保存就能看见**，边打边提示，改对自动消失。
  没午休就把午休填 00:00 – 00:00。

【目标里的钱是怎么算的】
  目标卡底部有一行：「已有 ¥320 + 今日 ¥242」
    · 已有 = 你手填的「已有存款」+ 以前攒下的历史累计
    · 今日 = 今天上班赚的（包含正在涨的那部分）
  两个加起来就是进度条上的钱。所以「已有存款」填 0 也没关系，
  今天赚的会自动算进去，不需要你每天手动改。

【请假不会让你白干】
  · 上午上了班、下午请假：上午那份照算，从请假那一刻起不再涨
  · 请假跨越午休：午休本来就不计薪，不会重复扣
  · 下班时如果当天请过假，结算也会按「扣掉请假」的时长算，不会白算


【点错了怎么办】
  · 不小心点了「下班啦」→ 按钮下方会出现「点错了？撤销下班」，点一下即可回去
  · 撤销后，已经赚的钱一分不少，从撤销那一刻接着算
  · 如果下班前你正在午休，撤销后会回到「午休中」，不会白算那段时间
  · 三种模式的收工都能撤销，不只是「打卡那一刻」
  · 午休点错了：再点一次「继续计时」就恢复了（中间那几秒不计薪）

【午休右边那个数字是什么】
  它不是「结束时间 − 开始时间」，而是**实际从工资时间里扣掉多少**。
  因为只有落在上班时间里那段才扣得到，落在班外的部分本来就不算工时。

  例（就是你现在这套配置）：
    · 班次 08:00 → 次日 07:00（23 小时）
    · 午休填 03:00 – 14:00（你写了 11 小时）
    · 次日 03:00 – 07:00 这段时间在班内，07:00 之后班已经结束
    · 所以右边显示「4 小时」，并提示「午休填了 11 小时，只有 4 小时在班内」
  想扣满 11 小时，就得让这 11 小时整段落在上班时间里。


【今天请假】
  时间轴右上角有个「请假」小按钮：
  · 点一下 = 停止计时，把已经干的那段结算掉，金额立刻冻住
  · 再点一下 = 从此刻重新开始计时，之前赚的不重算
  例：09:00 打卡、10:00 请假、18:00 取消 → 已赚仍是 1 小时的钱


【改参数不会重算今天】
  改月薪、改工时、换模式时，程序会先把「已经干的那段」按旧参数结算掉，
  再按新参数继续。所以改月薪不会让今天已经赚的钱突然翻倍。


【这些数字怎么算的】
  设置面板最下面有「这些数字怎么算的？」，点开逐条列出：
  日薪、有效工时、时薪、分薪/秒薪、今日已赚 的公式。


【回到首次使用（清空全部数据）】
  设置面板最下面「数据备份」里有一行小字「回到首次使用（清空全部数据）」：
    · 点第一下变成「点第二下：清空并重来」，3.5 秒内再点一下才真的清
    · 清完自动重新加载，会像第一次打开那样弹出设置面板（月薪、班次全是默认值）
    · 清的是本机这份配置：累计金额、已有存款、每日明细、补录、请假、目标全部归零
    · 想留个后路就先「导出数据」；导入时自动留的 .bak 也还在
    · 只是想把「今天」归零、保留月薪和班次，用下面的「清零累计」就够了

【清零累计】
  设置面板左下角那个「清零累计」，点第一下会变成「真的要清零？」，
  3 秒内再点一次才真清空——防手滑。超过 3 秒自动取消。

  它会清掉：历史累计金额、已有存款、今天的打卡记录、
            今天的补录记录和请假标记（界面上的「今日已赚」会真的归零）。
  不会清：月薪、班次、目标设置，以及以前每一天的明细。


【目标怎么改】
  点目标卡右上角「改一下」，可以改目标名称、金额、
  表情图标，以及「已有存款」（之前攒的部分也算进去）。
  攒满 100% 会有撒花。


【置顶】
  标题栏那个图钉 📌，点一下窗口就固定在最上层。
  程序只允许开一个窗口，重复双击会跳到已有的那个。


【数据存在哪】
  全部在你自己的电脑上：
    C:\Users\你的用户名\AppData\Roaming\打工人记账器
  不联网、不上传、没有账号。删掉上面这个文件夹 = 恢复出厂。

【数字框右边那两个小箭头】
  · 月到手、工作天数、每日有效工时、目标金额、已有存款，右边都有一对粉色小箭头
  · 点一下向上 = 加一档，点一下向下 = 减一档：
      月到手 / 存款：每档 100 元
      工作天数 / 工时：每档 0.5
      目标金额：每档 1 元（清空后连点是 1、2、3，不会一上来就 1、101、201）
  · 清空后点向上，从"该填的最小值"开始，不会跳一个奇怪的数出来
