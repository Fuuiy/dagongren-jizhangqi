# 打工人记账器 v1.2.0

这一版几乎全是「用起来别扭」的地方，功能没加多少。

## 首次使用不再蒙人

以前不填参数直接点「收起」，会拿默认的 ¥8,000/月 开始记账，还假装你没设置过（下次打开又弹面板，但记录里已经有当天收入）。

现在点「收起」会先问一句：

> 还没填你的工资 —— 直接关掉的话，会按现在的 ¥8,000/月 · 21 天 · 09:00–18:00 开始记账。

- 选「回去填」→ 留在面板
- 选「先用默认值」→ 才开始，但首页顶部会一直挂一条黄条，点它就能回来改
- 只有点「存好啦」才算你亲自确认过

## 切计时方式先问一句

三种方式算钱口径不同，切换会清零当天的计时金额。以前是点完保存直接没，现在会告诉你「今天这 ¥142.86 会清零」，点「先不换」就什么都不变。手动补录的钱始终保留。

## 其它改动

- **加班费倍率**：1 / 1.5 / 2 倍（只影响补录的班外加班）
- **点 × 的行为可选**：收到右下角继续计时（默认）/ 直接退出
- **小屏不再被裁**：窗口高度自动压到工作区内（1366×768@125% 也能完整显示），版面缺口时先收吐槽、再收换算卡，打卡按钮永远在
- **托盘图标按屏幕缩放取 16/24/32px**，高 DPI 不发虚
- **保存有反馈**：轻提示「存好啦 ♡」
- **快捷键**：Ctrl+Enter 打卡/下班、Ctrl+B 午休、Ctrl+, 设置
- **数据路径可见可复制**：设置里直接显示真实目录
- **默认值会提示**：首启工资下方写明「这是默认值」
- **秒薪主卡改 2 位小数**，精确 4 位放鼠标提示里
- **目标达成后有「换下一个目标」**
