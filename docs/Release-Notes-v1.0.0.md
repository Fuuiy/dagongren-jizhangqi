# 打工人记账器 v1.0.0

第一个对外版本。

## 这是什么

一个 Windows 桌面小挂件，把月薪换算成「每秒进账」——打开就打卡，屏幕上的金额一毛一毛往上跳，顺便告诉你「今天的收入 ≈ 25.8 杯奶茶」。

## 下载

- `打工人记账器-1.0.0-安装包.exe`（约 88 MB，Windows x64）
- 双击 → 下一步 → 完成；不需要管理员权限，装完桌面/开始菜单都有图标

> 首次运行若弹出蓝色 SmartScreen「未知发布者」提示，点「更多信息 → 仍要运行」即可（个人项目未购买代码签名证书，属正常现象）。

## 这个版本能做什么

- **三种计时方式**：打卡那一刻 / 定点打卡（提前 30 分钟提醒）/ 全自动
- **实时换算**：日薪、时薪、分薪、秒薪四联；每秒进账按毫秒刷新
- **时间轴**：按真实打卡画区间，收工后显示实际收工时刻
- **目标进度**：还差多少钱、约几个工作日
- **午休暂停**、**补录**（班外算加班、不封顶）、**请假**、**忘下班提醒**
- **明细与历史**：按日/按月，修改留痕可撤回
- **小窗模式**：424×216 便签贴在屏幕角落
- **数据 100% 本地**，支持 JSON 导出/导入；卸载不删账

## 已知限制

- 只提供 Windows x64 版本（未编译 macOS / Linux）
- 安装包未签名，会有 SmartScreen 提示
- 加班费按 1 倍计算，未做 1.5 / 2 倍法定倍率
