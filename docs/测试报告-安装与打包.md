## 三、已知事项（如实说明）

1. **未做代码签名**（个人软件常规做法）：部分用户首次运行安装包时，Windows SmartScreen 会弹「未知发布者」蓝色提示，点「更多信息 → 仍要运行」即可；这是所有无签名软件的正常现象，不是病毒。
2. 首次启动若弹出防火墙提示（联网拉取节假日安排），允许或拒绝均可——拒绝后节假日功能自动降级，其余功能不受影响。
3. 测试机上一个 200KB 的临时目录 `.preview/inst-test/resources/app.asar` 被系统进程锁定暂无法删除（早前一次卸载时应用进程未完全退出所致），重启后手动删除即可，不影响任何功能。
4. 版本号已统一为 **1.0.0**：package.json、页脚 ver、exe 版本资源三处一致（内部 1.11.x 为开发迭代号，对外首发即 1.0.0）。
