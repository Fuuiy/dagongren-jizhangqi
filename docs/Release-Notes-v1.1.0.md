# 打工人记账器 v1.1.0

## 新增

- **关闭到托盘**：点窗口右上角的 × 不再退出，而是收进 Windows 右下角通知区继续计时。
  - 点图标 = 显示 / 隐藏；右键菜单：显示主界面 / 缩成小窗 / 退出
  - 第一次收起会冒气泡提示「还在后台计时」
  - 窗口藏在托盘时，再双击桌面图标也能叫回来（不会开第二个）
  - 任务栏图标消失是正常的（收到托盘了）

## 修复

- **切换计时方式后首页金额不归零**：以前从「全自动」切到「打卡那一刻」，上午已经算出来的钱会挂在首页继续往上加。
  现在切换并保存后，旧口径的钱一律作废、首页从 0 开始。
- **切完模式会「自动帮你上班」**：以前切到打卡模式会凭空生成一个正在计时的段（状态直接「工作中」）。
  现在切换后是「还没打卡」，要你自己点。
- 切换时**保留**人工补录的钱（那是用户自己加的，不该被抹掉）；历史里别的日期一律不动。
