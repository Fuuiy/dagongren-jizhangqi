# 打工人记账器 v1.2.3

## 修复：补录列表的时间和钱对不上

以前在全自动/定点打卡模式下补录，写进记录的是**你输入的整段**，但只对班外那截计薪。于是出现：

```
09:00 – 18:00   1 小时   +¥47.62     ← 9 小时的范围，1 小时的钱
```

更麻烦的是这条记录**占住了 09:00–18:00 整段**，之后想补 17:00–18:00 会被判「重叠」，
而那 8 小时班内时间其实从没给过钱。

现在记录里存的是**真正入账的时段**（`parts`），列表显示、重叠判定、写入存档都用这同一份：

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 补 09:00–18:00（班次 09:00–17:00） | 显示 09:00–18:00 / 1 小时 | **17:00–18:00 / 1 小时** |
| 补完再补 17:00–18:00 | 判重叠（错） | 判重叠（对） |
| 补完再补 08:00–09:00 | 判重叠（错，被挡住） | **可以补** |
| 提示文案 | 「这段 09:00–18:00（1 小时）」 | 「**只补 17:00–18:00 这一段**（1 小时·班外加班）」 |
| 跨班前班后 | 显示一整个大区间 | 「只补 08:00–09:00、17:00–18:00 **这 2 段**」 |

## 老数据自动修正

旧版本留下的补录记录会在启动时按当时班次推断出真正入账的段，不用手动删了重补。

## 顺带

- 删除按钮的两下确认（防误删）补上了测试
