# 打工人记账器 v1.0.1

v1.0.0 之后的第一个更新，这一版集中修「用起来不对劲」的地方，并去掉无关的品牌标识。

## 新增

- **关闭到托盘**：点窗口 × 不退出，收进右下角通知区继续计时；右键托盘可显示 / 缩成小窗 / 真退出；图标按屏幕缩放取 16/24/32px，高 DPI 不发虚
- **首启必须确认**：不填工资就关面板，会先问「按默认 ¥8,000 开始吗」；用默认值时首页挂一条黄色提醒（点它或点「改一下」都能回去改），只有点过「存好啦」才算亲自确认
- **切换计时方式先问一句**：会写明「今天这 ¥X 会清零」，取消就什么都不变；确认后本班从切换那一刻起算，不会按早上 8 点把切之前的时段补算一遍
- **打卡那一刻的「应工作」**：班次时间只是参照，首页显示「已工作 xx:xx:xx / 应工作 8:00」，时间轴下方给出应工作时段与完成度；没干满就下班会先提醒差多少，超时会提示「按加班算」
- **加班费倍率**：1 / 1.5 / 2 倍可选（只作用于补录的班外加班）
- **快捷键**：Ctrl+Enter 打卡/下班、Ctrl+B 午休、Ctrl+, 设置
- **小屏自适应**：1366×768@125% 也能一屏放下，打卡按钮永不被裁

## 修复

- **切换计时方式后金额不清零 / 又冒出来**：旧口径的钱现在整笔作废（人工补录保留），且从切换时刻起算，不会出现「弹窗说从 0 开始、屏幕却显示 ¥380」
- **补录记录时间和钱对不上**：以前会出现「09:00–18:00 · 1 小时」这种自相矛盾的记录，还会挡住后续补录；现在只记真正入账的时段（如 17:00–18:00 · 1 小时），老记录自动修正
- **改班次后「已工作」与金额不一致**（甚至出现 15 小时）：已收工的工时现在用真正结算的秒数
- **程序替你打卡**：切到打卡模式后不再凭空进入「工作中」，必须自己点打卡
- **默认值提醒消失**：版面收紧时提醒压成一行但仍可见，不再出现「提示让你点黄条、黄条却不见了」
- **小窗偶发高度错误**、**页面溢出 1px** 等版面问题
