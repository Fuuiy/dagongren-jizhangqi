# 打工人记账器 v1.2.1

这一版补齐「打卡那一刻」的语义：**班次时间只是参照，真正算钱的是你的打卡。**

## 新增

- **应工作参照**：首页「已工作」后面跟 `/ 8:00`；时间轴下方一行
  `应工作 8:00（参照 08:00–17:00，含午休 60 分钟）· 已完成 50%`
  应工作时长 = 上班到下班 − 午休
- **下班前校验**：没干满就点「下班啦」会先提醒「今天算 4:00，比应工作的 8:00 少 4:00」，
  可以选「再干一会儿」或「照样下班」（按实际工时结算，不硬拦）
- **超时提示**：超过应工作后收工，提示「超出应工作 1:00，按加班算」，加班时长单独显示
- 设置里明确写「打卡模式下这两个时间只作参考」

## 修复

- 迷你小窗里「默认值提示条」把卡片挤出横杆（窗口高度算漏了 34px）
- 首页刚好溢出 1px 时不触发收紧，导致内容被切掉一点点
- 小屏（574 高度）下还差 6px 放不下

## 测试

18 个套件 / 196 项断言；新增 `run-clickmode.js`（10 项）。覆盖率行 96.0%、函数 91.9%。
